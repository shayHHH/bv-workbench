# Product

## Register

product

## Users

代理人、前台运营、客户准入运营、合规审核人员、财务出款人员和系统管理员。用户在办公室环境中处理客户资料、补件、报价确认、钱包地址校验、现金交收、链上查 U、银行水单匹配、银行送审、出款凭证和佣金核算。主要任务是快速识别当前责任、完成必要操作，并随时追溯一笔交易的完整过程。

## Product Purpose

把分散在网页、聊天和表格中的客户准入、交易执行与资金运营流程整合成可追踪的 Bitvast 工作台。Demo 的成功标准是让业务人员在一次演示中看懂 U换现金、现金换U、U换转账、转账换U、法币换法币从建单到完成归档的闭环，并能发现需要进一步确认的规则。

## Brand Personality

专业、克制、可信。文案清楚直接，关键状态和下一步责任明确，让用户在处理敏感客户资料时感到系统稳定、严谨且可控。

## Anti-references

不采用传统银行后台常见的老旧表格堆叠、狭窄字号、颜色繁杂和层级混乱；不使用装饰性金融图形、夸张渐变、玻璃拟态或缺乏业务意义的动画；不把所有信息包装成相同卡片。

## Design Principles

1. 下一步优先：每个页面首先说明当前状态、责任人和可执行动作。
2. 一条交易一条时间线：资料、审批、地址、库存、凭证、银行、出款和佣金事件可以连续追溯。
3. 自动化给建议，人员做决定：OCR 和风险规则提供依据，但不替代人工确认。
4. 敏感信息最少暴露：同名匹配和列表只展示完成任务所需的脱敏字段。
5. 复杂流程保持可读：通过角色视角、渐进披露和一致的状态语言控制信息密度。

## Accessibility & Inclusion

以 WCAG 2.1 AA 为基准。状态同时使用文字、形状和颜色表达；支持键盘焦点、清晰标签和减少动画偏好；正文与关键控件保持足够对比度和触控尺寸。
